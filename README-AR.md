# نظام إدارة قسم المونتاج — دليل التجهيز

## ما الذي ستحصل عليه؟
- `manager.html`: لوحة المدير الخاصة.
- `employees.html`: صفحة الموظفين العامة برابط مباشر، دون حسابات للموظفين.
- `app.js`: وظائف الموقع والتحديث الفوري.
- `config.js`: إعدادات الاتصال بقاعدة البيانات.
- `schema.sql`: إنشاء الجداول والصلاحيات.

## تنبيه مهم
لا يمكن جعل التعديلات تظهر على أجهزة مختلفة باستخدام ملف HTML وحده أو `localStorage`. يلزم خادم/قاعدة بيانات مشتركة. هذا المشروع يستخدم Supabase بخطته المجانية الحالية (قد تتغير حدود الخطة وسياساتها). الموظفون لا يحتاجون اشتراكاً أو حساباً؛ المدير وحده يحتاج حساباً.

## خطوات الإطلاق
1. أنشئ مشروعاً في https://supabase.com/dashboard
2. افتح SQL Editor في المشروع، والصق محتوى `schema.sql` ثم نفّذه.
3. من Project Settings > API انسخ Project URL ومفتاح `anon` أو `publishable` العام.
4. افتح `config.js` واستبدل:
   - `https://YOUR-PROJECT.supabase.co` برابط مشروعك.
   - `YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY` بالمفتاح العام.
   لا تستخدم `service_role` أو `secret key` في الموقع.
5. من Authentication > Users أنشئ مستخدم المدير ببريدك وكلمة مرور قوية.
6. انسخ UUID لحساب المدير، ثم نفّذ في SQL Editor:
   `insert into public.admin_users(user_id) values ('UUID-هنا');`
7. ارفع جميع الملفات إلى مستودع GitHub جديد أو مستودع خاص بالموقع، ثم فعّل GitHub Pages من Settings > Pages واختر فرع النشر والمجلد الجذر.
8. بعد النشر ستكون الروابط عادة:
   - صفحة الموظفين: `https://USERNAME.github.io/REPOSITORY/employees.html`
   - صفحة المدير: `https://USERNAME.github.io/REPOSITORY/manager.html`

## الأمان
- صفحة المدير لا تكفي حمايتها بإخفاء رابطها؛ لذلك قاعدة البيانات تفرض صلاحيات المدير عبر RLS والتحقق من جدول `admin_users`.
- لا تشارك كلمة مرور المدير.
- رابط الموظفين عام ويمكن لأي شخص يملكه مشاهدة بيانات الدوام والمهام والتوجيهات. لا تضع فيه معلومات سرية.
- الموظف يستطيع إرسال إنجاز فيديو فقط، ولا يستطيع تعديل الدوام أو اعتماد الإنجازات أو حذف البيانات.
- لا تضع مفتاح `service_role` في ملفات HTML أو JavaScript.

## ملاحظات النسخة الحالية
هذه نسخة تأسيسية قابلة للنشر، وتشمل جدول المناوبات، التوجيهات، قائمة الموظفين والمهام، إرسال الإنجازات واعتمادها، وتحديثات Realtime. بعض وظائف الملف الأصلي مثل إدارة الموظفين المتقدمة وتصدير Excel/CSV وتصميم الطباعة تحتاج استكمالاً قبل اعتبارها مطابقة كاملة للنسخة القديمة.
